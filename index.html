🎯 Tantangan

        
Pecah masalah "membuat program penghitung luas dan keliling persegi panjang" menjadi langkah-langkah kecil, lalu tulis kodenya.

        
        
panjang = int(input("Panjang: "))
lebar = int(input("Lebar: "))

luas = panjang * lebar
keliling = 2 * (panjang + lebar)

print("Luas:", luas)
print("Keliling:", keliling)

🎯 Tantangan

        
Ubah aturan menjadi lebih detail: 95–100 → A+, 90–94 → A, 85–89 → B+, 80–84 → B, 75–79 → C, <75 → D. Bagaimana urutan elif-nya?

        
        
if nilai >= 95:
    kategori = "A+"
elif nilai >= 90:
    kategori = "A"
elif nilai >= 85:
    kategori = "B+"
elif nilai >= 80:
    kategori = "B"
elif nilai >= 75:
    kategori = "C"
else:
    kategori = "D"

🎯 Tantangan

        
Tambahkan data nama_peminjam dan lama_pinjam, lalu tampilkan info peminjaman hanya jika status "dipinjam".

        
        
judul = input("Judul buku: ")
status = input("Status (tersedia/dipinjam): ")

if status == "dipinjam":
    peminjam = input("Nama peminjam: ")
    lama = input("Lama pinjam (hari): ")
    print(judul, "dipinjam oleh", peminjam, "selama", lama, "hari")
else:
    print(judul, "dapat dipinjam.")

🎯 Tantangan

        
Tulis algoritma bahasa manusia dulu, baru kodenya: tentukan apakah sebuah tahun adalah tahun kabisat (habis dibagi 4, kecuali habis dibagi 100 tapi tidak habis dibagi 400).

        
        
tahun = int(input("Tahun: "))

if (tahun % 4 == 0 and tahun % 100 != 0) or (tahun % 400 == 0):
    print(tahun, "adalah tahun kabisat")
else:
    print(tahun, "bukan tahun kabisat")
